# Student Internship Portal

## Project Overview
The Student Internship Portal is a web application developed using React.js to help students explore available internship opportunities. It displays internship information such as internship title, company name, and duration. Students can view internship details and navigate between different sections of the portal.

## Features
- Display available internships.
- View internship details.
- Navigate between Home and My Applications.
- Display company names and internship durations.
- Simple and user-friendly interface.
- Reusable React components.
- Responsive and attractive user interface.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Execution

### Step 1: Clone the Repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder
```bash
cd student-internship-portal
```

### Step 3: Install Dependencies
```bash
npm install
```

### Step 4: Run the Application
```bash
npm run dev
```

Open the local URL displayed in the terminal to view the application.
